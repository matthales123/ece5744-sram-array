# ECE 5744 — SRAM Array Design

SRAM array, SRAM cell, and write-driver schematic/layout source preserved within the original course library. Supporting sense-amplifier, decoder, gate, and stimulus cells are included to retain the available dependencies. The saved source does not contain a complete final report establishing system-level validation; this repository presents the design archive without asserting a completed SRAM signoff.

Open the included OpenAccess cell directories in Cadence Virtuoso with the course technology library/PDK configured locally. Preserve cell names and schematic/symbol/layout directory structure; configure `cds.lib` for your local library paths. The process technology, model files, and licensed Cadence tools are external prerequisites. Public files include editable schematic/layout databases and saved analysis configuration, but exclude generated extracted views and simulation output. No new DRC/LVS or simulation pass is claimed.

Original ECE5744 repository credits: Matt Hales and Shaotian Zhang.

Source comments retain course, instructor, library, and collaborator attribution. This repository does not grant a new license over third-party material. Generated logs, waveforms, debugging captures, and result directories are omitted from this public source edition.
